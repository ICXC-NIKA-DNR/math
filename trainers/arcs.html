Setup reference
L = ∫ab √1 + [dy/dx]² dx, or ∫ √1 + [dx/dy]² dy when the curve is written x = g(y).
Parametric: L = ∫ √[x′(t)]² + [y′(t)]² dt.
Polar: L = ∫ √r² + [dr/dθ]² dθ.
The perfect-square trick: if y′ = a·xp − 14ax−p then the cross terms cancel to +½, so 1 + [y′]² = (a·xp + 14ax−p)² and the radical disappears.
Identities that clear the radical: 1 + tan²θ = sec²θ · 1 + cot²θ = csc²θ · 1 + sinh²u = cosh²u.
Worth memorising: ∫sec θ dθ = ln|sec θ + tan θ| · ∫√1+u² du = ½(u√1+u² + ln|u + √1+u²|).
